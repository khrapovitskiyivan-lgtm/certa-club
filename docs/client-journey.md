# Certa: клиентский путь

Версия от 18.10.2026, поздний вечер (витрина первой версии). Отметки: [есть] уже работает на сайте, [план] спроектировано, не сделано, [вопрос] нужно решить.

## Роли

- **Гость**: случайно зашёл на сайт. Видит только CERTA, подпись и «Вход по приглашению».
- **Кандидат**: получил личное приглашение.
- **Участник**: прошёл проверку и подтверждён советом.
- **Эксперт**: участник, который даёт оценку и заключения по экспертизе. [есть роль, права — план]
- **Экспертный совет**: принимает людей, выдаёт приглашения, назначает роли, разбирает споры. [есть]
- **Куратор**: ведёт сделки и связывает стороны по откликам. Сейчас это экспертный совет.

## 1. Приглашение [есть]

1. Совет в кабинете создаёт приглашение на имя кандидата, срок 1–60 дней.
2. Ссылка показывается один раз. Совет отправляет её лично. Не открывать самому: она одноразовая.
3. В мессенджере ссылка выглядит карточкой «Приглашение в Certa».
4. Кандидат открывает ссылку где угодно, в том числе прямо из Telegram: регистрация работает во встроенных браузерах мессенджеров.

## 2. Вступление [есть]

1. **О клубе**: что такое Certa, как устроено, конфиденциальность, что дальше. [вопрос: тексты правят основатели]
2. **О вас**: имя, почта, телефон (маска +7, иностранные номера свободно), город (подсказки), род занятий, «чем поделиться» (необязательно), псевдоним, **пароль от 8 символов**, согласие с правилами. Об активах не спрашиваем.
3. **Сразу витрина**: после анкеты участник попадает на витрину и смотрит лоты. Размещать («Предложить», «Ищу») и откликаться нельзя: вместо формы подсказка «пройдите верификацию».
4. **Верификация, когда нужна**: лично через провайдера [план: провайдер не выбран, пока ссылку присылает куратор] или через агента (банк, семейный офис, представитель). После отправки «на рассмотрении», витрина остаётся открытой.

Короткая регистрация: О клубе, О вас. Верификация отложена до первого действия. Face ID не нужен.
Экспертиза вещи не нужна для размещения: её назначают по ходу сделки, по требованию покупателя или по желанию продавца [план].

## 3. Решение совета [есть]

Кабинет совета показывает человека по статусу:
1. «Приглашения»: ждёт / использовано / отозвано / истекло. Неиспользованное можно **отозвать**.
2. «Не завершили вступление»: заполнил анкету, не отправил верификацию. Можно **удалить регистрацию**.
3. «На рассмотрении»: отправил верификацию, видна анкета, кнопка «Подтвердить участие».
4. «Участники»: подтверждённые, у каждого выбор роли (участник, эксперт, совет).
5. «Журнал»: все события клуба с датой и временем, без срока хранения.

## 4. Повседневный вход [есть]

1. **Почта и пароль**: главная → «Вход по приглашению» → почта → появляется поле пароля → клуб. Работает в любом браузере, включая Telegram. При ошибке ответ всегда «Неверная почта или пароль»: посторонний не узнает, кто участник. Вход помнится 30 дней. Страница /login делает то же самое.
2. **Face ID по желанию**: после входа в обычном браузере (Safari, Chrome) вверху страницы тихая строка «Включить вход по Face ID? Включить · Не сейчас». Во встроенных браузерах мессенджеров её нет. Кто включил, дальше входит одним касанием: Face ID, отпечаток или код-пароль телефона.
3. **Забыли пароль?**: ссылка на почту (15 минут, одноразовая), по ней вход. Ответ всегда одинаковый. [план: письма заработают после подключения почтового сервиса]
4. **Без пароля**: кто регистрировался в период входа только по Face ID, видит строку «Задайте пароль для входа по почте».
5. **Ключ Face ID**: новое устройство добавляется только из уже вошедшего; о каждом новом ключе приходит письмо.
6. **Потеря доступа к почте и устройствам**: восстановление только через совет. [план: кнопка сброса в кабинете]

## 5. Витрина [есть, первая версия]

Доступна только подтверждённым участникам. Меню клуба: Предложения · Ищут в клубе · Предложить · Ищу · Совет (для совета) · Выйти.

**Продавец, раздел «Предложить»** [есть]
1. Категория (часы, ювелирные изделия, искусство, коллекционные предметы), название, описание.
2. Цена в ₽, $ или €, либо «по запросу».
3. **Страна и город, где находится предмет**, без точного адреса (подсказки стран и городов).
4. «Тихий лот»: не показывается в общей ленте, его видят только автор и совет, куратор предлагает его лично.
5. Лот можно снять в любой момент.
6. Фото: сейчас только у тестовых лотов. [план: загрузка фото и документов о происхождении после подключения файлового хранилища]
7. Экспертиза заранее с отметкой «проверено». [план]

**Покупатель** [есть]
1. Лента «Предложения клуба»: фото, категория, название, цена, страна и город, псевдоним продавца. Фильтры по категории и стране.
2. Раздел «Ищу»: что ищу, бюджет (необязательно), страна и город, где удобно получить. Запросы видны во вкладке «Ищут в клубе».
3. Отклик: «Запросить» у лота или «Есть у меня» у запроса, с комментарием. Отклик уходит куратору, стороны напрямую не связываются.

**Совет** [есть]
- Блок «Отклики»: кто, по какому объявлению, кому, комментарий, кнопка «Стороны связаны».
- Может снять любое объявление.
- Тестовые лоты: кнопки «Создать тестовые лоты» и «Снять тестовые» (6 демонстрационных объявлений с рисунками).

## 6. Сделка [план]

1. Согласование условий через куратора.
2. Экспертиза подлинности: обязательна до договора, если её не было. Заключение даёт эксперт.
3. Выбор способа расчёта (банковский эскроу, нотариальный депозит, аккредитив, крипто-эскроу через агента). Сразу видно, раскроются ли стороны друг другу.
4. Договор с электронной подписью.
5. Расчёт через агента → передача предмета → подтверждение.
6. Закрытие, комиссия удерживается агентом расчёта.
7. Спор после расчёта: сделка замораживается, решает медиатор клуба.
